# data/sports

Save the CSV file(s) you download from the SCORE Sports Data Repository (https://data.scorenetwork.org/) here.

Your data files can stay as you downloaded them from SCORE, names included. Never use a name, bib, team or judge column (for example in the Boston Marathon, powerlifting or MMA data) in a plot, a table or a slide: your reports and slides never show a private person's name.
